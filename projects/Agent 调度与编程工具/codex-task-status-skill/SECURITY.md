# Security and privacy

`task-status` manages Codex task titles. A title may reveal the subject of a
private project, so review screenshots and bug reports before publishing them.

## Safe bug reports

- Prefer the fictional demo image in `docs/task-status-demo.png`.
- Remove task titles, local paths, email addresses, repository names, customer
  names, API keys, tokens, and conversation text from screenshots and logs.
- Do not upload the local Codex task database, rollout files, or `AGENTS.md`.
- Reproduce title-format bugs with placeholders such as `原任务` or
  `Example task`.

## Scope

The Skill changes Codex task titles only through Codex task capabilities. It
does not grant permission to send messages, publish content, archive tasks,
change pin state, or modify ordinary ChatGPT conversations.

For a private security report, contact the repository owner through GitHub.
