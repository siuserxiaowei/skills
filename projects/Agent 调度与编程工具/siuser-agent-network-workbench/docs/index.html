Dashboard 中英文对照

上游 Dashboard 菜单本身还是英文，但工作台生成的任务、角色和演示消息都已经改成中英文对照。先按这张表看。

Tasks

它能先服务三件事

第一期不做公网服务，不接客户生产环境。它更像你自己的本地运营中枢，让日常内容生产和 Skill 维护变得可追踪。

Obsidian 日报

读取本地 Markdown 和日报管线输出，生成可复盘、可公开前检查的日报草稿。

  • 不展示原始聊天内容
  • 只写入指定日报目录
  • 给出公开性检查清单

公众号生产

把素材变成标题、结构、初稿、配图提示词和发布清单，适合长文生产前的第一轮整理。

  • 区分事实、观点和建议
  • 保留参考资料线索
  • 审校后再发布

Skill 工厂

围绕你的安全扫描、视觉审美、微信文章读取等 Skill 做只读检查和维护报告。

  • README/SKILL.md 检查
  • 本地脚本验收
  • 不自动 push 或发布

本地怎么启动

克隆仓库后，先跑 doctor 和 init，再启动只监听 127.0.0.1 的 Hub 和 Dashboard。

git clone https://github.com/siuserxiaowei/siuser-agent-network-workbench.git
cd siuser-agent-network-workbench
npm install
npm run doctor
npm run init
npm run demo:article
# Dashboard
http://127.0.0.1:3000

# 验证本地任务流
npm run smoke
npm run smoke:send-task

# 停止本地服务
npm run stop:local

安全边界

这个项目的价值前提是本地优先。它可以组织 Agent 工作，但不能替代你的最终判断。

不上传私密数据微信聊天数据库、导出的 Markdown、图片、Obsidian vault 和 secrets 都不进入仓库。
不暴露公网Hub 和 Dashboard 默认只绑定 127.0.0.1，适合本机使用。
不自动发布删除、push、发布网页、修改主 vault 笔记，都需要你单独确认。
