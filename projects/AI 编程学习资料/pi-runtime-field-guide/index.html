Pi 的答案：把循环、错误、上下文与历史做成明确数据结构，而不是藏在一个“run()”黑盒里。

本指南的答案：每章先留三个问题；源码结论链接固定 commit，版本变化单独记账。

01 / FIVE FINDINGS

先建立五个
不会过期的判断

01

“停止”不是一个布尔值

模型 stopReason、tool terminate、shouldStopAfterTurn、steering 与 follow-up 队列共同决定一轮是否真的结束。

02

工具失败 ≠ 供应商失败

网络与限流可透明退避；带副作用的工具不能无脑重试。幂等键、重放策略与副作用分类必须在模型之外。

03

压缩是上下文重建

Pi 保留 recent tail、摘要旧内容，并守住 tool call/result 边界。它不是粗暴截断消息数组。

04

树让回退自然发生

Pi 在单一 JSONL 内用 parentId 构成 entry tree；DSH 则让单 session 保持线性、跨 session fork 成谱系。

05

安全边界不能靠提示词

Pi 官方明确没有内建权限系统。Hook 负责可拦截，sandbox、policy、approval、secret broker 与审计仍要外置。

02 / VERSION DEBT
TEACHING BASELINEv0.80.2

  • pi-ai 与低层 Agent Loop
  • 工具管道、消息与事件
  • coding-agent 压缩与会话树
→DO NOT SILENTLY UPGRADE THE CLAIM
CURRENT STABLEv0.84.3

必须新增的进阶轨

  • durable AgentHarness
  • entry / register / usage ledger
  • 原子事务与 tool replay safety

本指南不把旧教程判为“错”，而是把每条结论标成：对 v0.80.2 成立、在 v0.84.3 仍成立、或 当前新增。
