# Compact execution protocol

## 案例入口

先读 [references/examples.md](references/examples.md)：其中给出正向案例、边界案例、失败恢复和可观察的验收证据；再按下文流程执行。

1. Define the outcome and the evidence that proves it.
2. Inspect current authoritative state before explaining the failure.
3. If an attempt repeats the same signature, change the hypothesis—not just the parameter.
4. Complete remaining safe in-scope actions; do not expand authority.
5. Ask only when a material user choice, credential, permission, or external side effect is genuinely required.
6. Verify the original path before claiming success; name every meaningful unchecked path.

Correction format: **observation → impact → next action**.

Use a direct, focused tone. Do not add threats, fake rankings, company impersonation, guilt, peer comparison, infinite retries, or unsupported praise.

Completion vocabulary: `verified`, `partially verified`, `unverified`, `blocked`.
