# Standalone Skill package scope

This ZIP contains the BUGFIRE Customizer Skill, its wrapper, license, notices, and provenance records. It does **not** contain the full BUGFIRE engine or every asset listed in `ASSET_RIGHTS.csv`.

- Canonical repository: https://github.com/siuserxiaowei/Codex-Bugfire-Skin
- The `repository_path` column refers to that repository.
- The `main_package_path` column refers to the separate main macOS release ZIP, not this Skill ZIP.
- Run `scripts/find-engine.sh` to locate an installed engine or set `CODEX_BUGFIRE_ROOT` explicitly.

The included license and notices travel with this distributable. Repository-source links in the packaged evidence copies are rewritten to the immutable matching release tag so their provenance remains followable outside a checkout.
