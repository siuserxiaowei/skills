# Lark Tasks｜案例与详细说明

以下案例以当前 lark-cli 的运行时发现结果为准；命令、schema、profile、identity 和租户都必须在执行当次重新确认。

## 正向案例

- **用户请求：** “给王明创建一个周五 18:00 截止的任务，带三项清单。”
- **处理：** 消歧负责人、解析带时区截止时间、核对清单/项目/可见性，展示完整预览后创建并回读。
- **验收证据：** task ID、负责人、截止时间/时区、清单和状态一致；没有误建到同名人员或错误清单。

## 边界案例

- **场景：** 完成、删除、批量改负责人或通知外部协作者是额外写操作，必须针对具体任务确认。
- **验收证据：** 任何额外写入、外部发送、权限或高风险动作均未越过用户本轮授权。

## 失败与恢复

- **场景与处理：** 创建超时先按幂等字段/标题与时间查询是否已存在；未知状态不重复创建。
- **验收证据：** 保留结构化错误、实际远端状态和下一步条件；没有把未知状态伪装成成功。
