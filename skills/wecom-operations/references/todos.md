# 待办操作

## 运行时能力

先运行 `wecom-cli todo --help`。只操作当前机器人被允许访问、且任务范围明确的待办；不要默认机器人能管理任意员工待办。

## 创建

写入前核对：

- 待办内容；
- 参与人；
- 截止时间与时区；
- 是否提醒，以及提醒相对截止时间的偏移。

需要提醒时必须有有效截止时间。成员标识通过获准的查找能力解析，无法唯一匹配就暂停，不猜 userid。执行创建前先读 `create_todo --schema`，以运行时字段定义为准。

## 查询、更新和状态变化

查询限制在用户指定或合理的短时间窗口。更新前读取详情；参与人字段如果采用整表语义，就保留未被用户要求删除的现有成员。

接受、拒绝、完成等参与状态变化与编辑正文是不同操作，使用 CLI 当前列出的对应能力。向用户反馈可读内容与状态，不展示 todo_id。

## 删除

删除前需要四步证据链：检索候选、读取详情、向用户复述内容/截止时间/状态、取得明确确认。确认只适用于该条待办，不能扩展成批量清理授权。

删除后再做一次只读查询并报告结果。若远端状态无法验证，说明删除请求的响应与未验证项，不把请求成功等同于对象已消失。
