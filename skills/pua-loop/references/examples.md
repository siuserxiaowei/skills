# Bounded evidence loop｜案例与详细说明

该系列的强度来自清楚的完成定义、短反馈回路和证据，不来自羞辱、操控、虚假权威或无限循环。

## 正向案例

- **用户请求：** “连续迭代这个页面，直到移动端、键盘和测试都过，但最多五轮。”
- **处理：** 先固定三个评价器与五轮预算；每轮只改一个主要失败类别，运行相同验收集，记录分数、回归和下一假设，满足条件即提前停止。
- **验收证据：** 循环表包含每轮输入、修改、证据和停止理由；通过意味着三个评价器均达标，而不是轮数用完。

## 边界案例

- **场景：** “一直循环直到完美”没有可验证上限；先定义评价器、预算、外部依赖和停止条件再开始。
- **验收证据：** 用户自主性、权限边界和事实准确性均被保留。

## 失败与恢复

- **场景与处理：** 两轮没有改善就触发换假设/缩小范围；第五轮仍未达标时交付真实 partially verified 状态，不伪造成功。
- **验收证据：** 新一轮必须产生新证据或新决策；没有把重复、语气或消耗本身当作进展。
