# Lark Sheets｜验收案例

示例中的工作簿 token、sheet ID、A1 范围、revision 与命令 flag 必须取自当前对象和 `lark-cli sheets ... --help`，不能从示例复制。

## 使用说明

- **何时使用：** 读取、批量写入、建模或维护飞书 Sheets 的值、公式、结构和对象。
- **准备/输入：** spreadsheet/sheet、A1 范围、revision、二维数据形状、类型规则、profile/identity 与写入授权。
- **执行方式：** 先回读目标和依赖作基线，按当前 help 预览/分块写入，再回读公式、边界和对象状态。
- **验收/边界：** 形状与类型保真、范围外不变、每批可对账；clear、删除、覆盖公式和历史回退需独立确认与恢复证据。

## 正向案例

### 导入 500 行并保留类型

- **用户请求：** “把 `sales.csv` 的 500 行写进‘八月’工作表，从 A2 开始，保留日期和公式，别动其他区域。”
- **准备信息/输入：** CSV 位于受控工作目录；用户给出工作簿链接或 token；目标 sheet 唯一；profile/identity 对该范围有写权限。
- **处理：** 运行 `lark-cli sheets --help`、`lark-cli sheets +workbook-info --help`、`lark-cli sheets +cells-get --help`、`lark-cli sheets +cells-set --help`；解析出 spreadsheet token、sheet_id、当前 revision 和 A2 起始范围；验证 500×N 的二维形状与日期/数字/布尔/公式类型；读取目标与边界单元格作基线，按当前 help 支持方式预览/分块写入；逐块记录结果并回读首尾行、公式错误与范围外哨兵单元格。
- **预期输出：** 500 行落入精确范围，类型与公式语义保真，范围外无变化。
- **验收证据：** 输入行列数、目标 A1 范围、写前/写后 revision、逐块 changeset、首尾样本、公式验证结果和范围外哨兵值。

## 边界案例

### 导入要求顺便清空整表

- **用户请求：** “先把整张表清空再导入，原公式不用留。”
- **边界判断：** 清空会删除公式、样式或依赖引用；尚无恢复快照或精确确认。
- **处理：** 先读取 used range、公式、合并、隐藏、冻结与依赖范围，展示将丢失的对象；把“写入新范围”和“清空/覆盖”拆成两个操作。未获得针对准确 sheet 和范围的确认前，只生成导入计划或建议新建 sheet。
- **预期输出：** 未确认时旧表不变；用户能在覆盖和新建之间作知情选择。
- **验收证据：** 写前 revision、影响范围/公式数量、恢复文件位置和零写入日志。

## 失败与恢复

### 第三批响应未知

- **场景：** 前两批成功，第三批提交后超时。
- **处理与恢复：** 不从第一批重放。用 `cells-get` 对第三批精确范围回读，按每行/单元格实际值区分已写、未写和冲突；只对确定未写且仍符合原 revision 计划的幂等子块重试，冲突项交给用户决定。
- **预期输出：** 已成功数据不重复，用户修改不被覆盖，部分完成范围准确可见。
- **验收证据：** 批次 ledger、每块 A1 范围、远端读回值、重试集合、最终成功/失败行数和当前 revision。
