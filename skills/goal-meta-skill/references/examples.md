# Goal Meta Skill｜案例与详细说明

以下案例把触发条件、处理决策和验收证据连在一起。示例中的账号、路径、对象和内容均为占位描述，执行时必须替换为用户已确认的真实范围。

## 正向案例

- **用户请求：** “帮我把‘把这些 Skill 做好’变成可持续执行的 Goal。”
- **处理：** 把模糊活动改写成结果：列出全量对象、原创与质量门槛、案例要求、自动验证、人工限制、停止条件和最终证据，同时保留用户授权边界。
- **验收证据：** 目标能区分完成、部分完成和阻塞；覆盖全部对象而非抽样；任何删除、发布或真实外部写入都没有被暗中授权。

## 边界案例

- **场景：** 单次可直接回答的小问题不创建 Goal；已有活动 Goal 时也不静默替换，除非用户明确要求切换。
- **验收证据：** 未获授权的动作没有发生，结果明确标记适用范围与剩余选择。

## 失败与恢复

- **场景与处理：** 预算接近耗尽或某次测试失败都不等于完成；记录剩余缺口，继续安全工作或在重复同一外部阻塞达到规则阈值后再标记 blocked。
- **验收证据：** 失败状态、已完成范围和下一次安全重试条件均可复核。
