# Imagegen Frontend Web｜案例与详细说明

以下案例把触发条件、处理决策和验收证据连在一起。示例中的账号、路径、对象和内容均为占位描述，执行时必须替换为用户已确认的真实范围。

## 正向案例

- **用户请求：** “为 SaaS 首页生成桌面与手机端一致的原创 Hero 视觉，并交给前端实现。”
- **处理：** 先确定内容层级、焦点、裁切安全区、文字策略和品牌 token；生成最小必要参考集，记录每张图的用途、宽高比、权利与实现说明。
- **验收证据：** 桌面/手机参考覆盖目标视口；关键主体不被裁切；图中没有不可控长文字；清单、哈希、alt 与前端映射齐全。

## 边界案例

- **场景：** 用户给出无权使用的竞品图并要求原样复制时，只能分析一般视觉属性，重新构图和生成，不把受保护图像打包进结果。
- **验收证据：** 未获授权的动作没有发生，结果明确标记适用范围与剩余选择。

## 失败与恢复

- **场景与处理：** 若生成图的标语拼错或移动端裁掉主体，保留已确认的方向，只重做文字层或目标视口素材；重新跑引用包校验后再交付。
- **验收证据：** 失败状态、已完成范围和下一次安全重试条件均可复核。
