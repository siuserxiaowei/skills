# Lark Slides｜验收案例

示例使用当前 `lark-cli slides ... --help` 发现的参数；presentation token、slide ID、元素 ID 与媒体 token 均从当次读回取得。

## 使用说明

- **何时使用：** 新建、追加、重建或局部编辑飞书原生 Slides，并需要结构与视觉双重验证。
- **准备/输入：** presentation/位置、逐页主张、可编辑性要求、合法素材、profile/identity 与变更范围。
- **执行方式：** 保存原 slide ID/XML/截图，规划页面和媒体，按当前 help 写入，再回读 XML 和全页截图。
- **验收/边界：** 页序、数据、元素和实际渲染一致；整体替换/删页是非原子高影响动作，必须有恢复证据和确认。

## 正向案例

### 追加三页可编辑的数据总结

- **用户请求：** “给现有飞书幻灯片追加三页八月数据总结，保持可编辑，原页面不要动。”
- **准备信息/输入：** 用户给出 presentation 链接、三页主张与有使用权的素材；目标插入位置明确；profile/identity 具备编辑权限。
- **处理：** 运行 `lark-cli slides --help`、`lark-cli slides +xml-get --help`、`lark-cli slides +screenshot --help` 及当前创建/更新命令的 help；读取原 slide ID 顺序、XML、主题和截图；为三页定义主张、元素和素材尺寸，必要时先上传媒体；展示变更计划后写入；再次读取 XML 和全页截图。
- **预期输出：** 三页位于指定位置，文本/图表数据正确且元素可编辑，原页面次序和内容不变。
- **验收证据：** 写前/写后 slide ID 序列、三页 XML、媒体来源清单、全页截图，以及对溢出、遮挡、对比度和字体替换的检查结果。

## 边界案例

### 要求像素级复制外部模板并替换整份

- **用户请求：** “照这个商业模板一模一样重做，并把旧 deck 全替换掉。”
- **边界判断：** 模板权利不明；整体替换超出普通追加范围且可能非原子。
- **处理：** 只提取一般布局、色彩和层级规律，要求用户确认素材权利；先交付原创页面方案。未保存原 XML/截图、未展示将删除的 slide ID、未获精确确认前，不执行 replace-pages 或删除旧页。
- **预期输出：** 不复制受保护的独特表达，不意外删除原 deck。
- **验收证据：** 来源/权利记录、原创差异说明、原页面备份和确认前零删除日志。

## 失败与恢复

### 非原子替换中途断开

- **场景：** 新页面已创建，但删除旧页面前连接中断。
- **处理与恢复：** 不重放整批；先用 `xml-get` 和截图重新取得实际 slide ID 顺序，标出新增、旧有和未知页面；按真实状态形成最小修复计划，删除任何旧页前重新核对确认。
- **预期输出：** 不产生重复新页或误删旧页，恢复以当前远端事实为准。
- **验收证据：** 中断前 ledger、恢复时 slide 序列、逐页截图、最小修复集合与最终 XML/视觉验收。
