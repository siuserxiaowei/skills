# Skill Vetter｜案例与详细说明

以下案例把触发条件、处理决策和验收证据连在一起。示例中的账号、路径、对象和内容均为占位描述，执行时必须替换为用户已确认的真实范围。

## 正向案例

- **用户请求：** “安装前审计这个下载来的 Skill。”
- **处理：** 先固化待审制品和哈希，再建立文件、能力、权限、网络与持久化图；做静态扫描和隔离测试，并把每个发现映射到证据、影响和控制。
- **验收证据：** 报告覆盖所有文件且无 skipped；高风险项有精确位置与复现；结论为 accept、accept-with-controls 或 reject，并列残余风险。

## 边界案例

- **场景：** Star、作者名气、市场上架或杀毒 0 报警都不能替代代码与行为审计；不在真实凭证和主目录上直接试跑未知 Skill。
- **验收证据：** 未获授权的动作没有发生，结果明确标记适用范围与剩余选择。

## 失败与恢复

- **场景与处理：** 扫描器把测试字符串误报成危险行为时，保留原始证据、人工复核上下文并修正规则；不得为了得到绿色报告简单加入忽略项。
- **验收证据：** 失败状态、已完成范围和下一次安全重试条件均可复核。
