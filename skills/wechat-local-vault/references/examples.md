# 微信私有快照｜验收案例

这些流程只处理用户有权访问的本机数据。快照、报告和素材包必须位于私有目录，回复中不粘贴 key、内部账号标识或大段私聊原文。

## 使用说明

- **何时使用：** 查询已解密微信快照、离线校验 key、生成新快照、导出指定聊天或准备群聊摘要素材。
- **准备/输入：** 授权数据集、原库/快照、准确会话与时区日期、已验证 key（仅解密需要）和全新私有输出。
- **执行方式：** 先 status/contact 消歧；查询只读，解密先检查 WAL，一次只处理明确范围并按 manifest 交付。
- **验收/边界：** 源库不变、结果条数/边界/权限可核对；默认隐藏内部标识，不控制微信、不注入、不解密媒体、不覆盖输出。

## 正向案例

### 导出某位客户八月沟通

- **用户请求：** “把客户甲 2026 年 8 月的文字沟通导出成 Markdown，放到这个私有目录。”
- **准备信息/输入：** 已有经过验证的明文快照；用户给出快照目录、私有且不存在的输出文件、日期边界与所用时区；不要求媒体解密。
- **处理：** 设置 `SKILL_DIR`，先执行 `python3 "$SKILL_DIR/scripts/vault_cli.py" --decrypted-dir <PRIVATE_SNAPSHOT> contacts --query "客户甲" --format text` 消歧；再用 `history` 小范围读取首尾消息核对边界；唯一命中后执行 `python3 "$SKILL_DIR/scripts/vault_cli.py" --decrypted-dir <PRIVATE_SNAPSHOT> export "客户甲" --start-time "2026-08-01" --end-time "2026-09-01" --format markdown --output <PRIVATE_REPORT.md>`（仅使用当前 `--help` 确认存在的 flag）。
- **预期输出：** 新建一份只含目标会话与时间范围的 Markdown；图片、语音和附件只保留类型提示。
- **验收证据：** 目标会话唯一、日期边界、导出消息数、报告权限/路径、快照标识，以及原始数据库哈希和修改时间未变化。

## 边界案例

### 只问未读群但出现同名对象

- **用户请求：** “告诉我有哪些未读群，不要泄露联系人信息。”
- **边界判断：** 查询只需群名、未读数与必要摘要；默认禁止显示 wxid/userName。
- **处理：** 运行 `python3 "$SKILL_DIR/scripts/vault_cli.py" unread --format text`；不添加 `--show-identifiers` 或 `--show-sensitive`。若同名群无法区分，停止并只说明歧义；只有用户明确需要本地消歧时才讨论最小标识输出，不能顺便导出全量联系人。
- **预期输出：** 输出最小群级信息；歧义未被猜测，敏感标识为零。
- **验收证据：** 实际使用的 flags、返回群数量、脱敏检查和没有生成额外导出文件的记录。

## 失败与恢复

### 源库存在非空 WAL

- **场景：** 运行全量或增量解密前发现源库旁存在非空 WAL，无法证明一致提交边界。
- **处理与恢复：** 立即停止该库，不复制一个“看起来可读”的残缺快照；提示用户退出微信后取得一致副本，再重新检查。若同批其他库成功，manifest 分别记录成功/失败，不自动重跑未知库。
- **预期输出：** 失败库不产生被误称完整的明文库，部分成功保持可用且边界清楚。
- **验收证据：** WAL 检查结果、失败库条目、成功/失败计数、恢复前置条件和原始文件未变化证明。

### 补充：群聊摘要素材与候选 key

- 群聊素材用 `digest-source` 生成 JSON/Markdown，不更新摘要 `history.json`；没有图片说明时只能写“图片内容不可见”。
- 已有授权工具留下候选日志时，仅运行 `extract_keys.py --match-only --targets all --db-base <WECHAT_DB_STORAGE>` 做离线首页校验；只报告通过数和缺失数，不显示 key、salt、wxid 或完整路径。
