# Beautiful HTML Templates｜案例与详细说明

以下案例把触发条件、处理决策和验收证据连在一起。示例中的账号、路径、对象和内容均为占位描述，执行时必须替换为用户已确认的真实范围。

## 正向案例

- **用户请求：** “把这份 12 页中文路演提纲做成原创、可离线打开的 HTML 演示文稿。”
- **处理：** 先整理受众、叙事和每页语义，再从设计轴推导一套新主题；用语义 JSON 构建单文件 HTML，并按键盘顺序、窄屏、投影尺寸、断网和打印逐项检查。
- **验收证据：** 所有 12 页内容完整；无远程运行时；键盘可翻页且焦点可见；375px 与 1280px 无横向溢出；打印预览逐页不截断。

## 边界案例

- **场景：** “照着某品牌发布会一比一复刻。”只提取高对比、留白、几何等一般属性，重新设计构图、图形和字体层级，不复制其独特表达。
- **验收证据：** 未获授权的动作没有发生，结果明确标记适用范围与剩余选择。

## 失败与恢复

- **场景与处理：** 若长标题在窄屏溢出，先缩短或重排信息，再调整响应式 token；不能用 `overflow:hidden` 把内容裁掉后声称通过。
- **验收证据：** 失败状态、已完成范围和下一次安全重试条件均可复核。
