# Beautiful HTML Templates｜可复现案例

## 使用说明

- **何时使用：** 用户确认 HTML 是主演示格式，并需要原创叙事、离线运行、键盘、响应式与打印行为。
- **准备/输入：** 受众/场合、演讲目标和时长、真实提纲/来源、页数范围、视口、素材权利、离线与打印要求。
- **执行方式：** 先构建逐页断言，再从内容推导 tokens 和构图；用安全 JSON 构建或扩展语义 HTML，并在真实浏览器逐页检查。
- **验收/边界：** 源 JSON 与 HTML 可交付，键盘/焦点/窄屏/投影/断网/打印证据齐全；不得仿制受保护发布会或把 HTML 冒充原生 PPTX。

## 正向案例

### 12 页离线中文路演

- **用户请求：** “把这份 12 页中文路演提纲做成原创、断网可开的 HTML 演示文稿，也要能打印。”
- **准备信息/输入：** 最终提纲、受众和 15 分钟时长、引用来源与截至日期、已授权图片、16:9 投影视口、手机阅读与打印要求、输出路径；HTML 是用户确认的主格式。
- **处理：** 先把每页改成一个可讲述的断言；从主题内容推导字体角色、12 列网格、留白、色彩和一个 motion 规则；在 JSON 中记录内容与素材 rights；运行 builder `--check` 和生成；断网打开实际 HTML，逐页检查键盘、焦点、hash、reduced motion、无 JS 阅读顺序、390px/1280px 与打印预览。
- **预期输出：** 可编辑 JSON 与单文件 HTML，各 12 页，原创视觉方向明确、无远程运行时依赖。
- **验收证据：** 12 个 slide label 唯一；Arrow/Home/End 可用且不抢按钮按键；390px 无横向溢出、1280px 投影文字可读；网络请求为零；打印一页一张且无裁切；图片路径和权利声明通过检查。

## 边界案例

### 要求复刻知名品牌发布会

- **用户请求：** “把某品牌发布会的字体、渐变、图形和每页构图一比一复刻，只替换文字。”
- **准备信息/输入：** 只有公开公开视频截图，没有品牌资产或模板授权。
- **边界判断/处理：** 不复制可识别的字体组合、独特图形和逐页构图；抽取“高对比、极少文字、中心舞台、克制动效”等一般属性，并根据当前研究主题重新推导网格、配色和图形；不把截图打包。
- **预期输出：** 服务当前内容的原创方向样张或待选设计轴，而不是品牌仿制品。
- **验收证据：** 主题 tokens、构图和图形可由当前 brief 解释；交付不含原截图、Logo 或原文案；素材 provenance 中没有未授权资产。

## 失败与恢复

### 窄屏长标题溢出

- **失败场景/用户请求：** “第 7 页中文长标题在手机上被裁掉，修好但别把字缩得看不清。”
- **准备信息/输入：** 生成的 JSON/HTML、390×844 失败截图、投影视口已通过、原文不可删的事实边界。
- **处理与恢复：** 先重排标题与副标题信息，必要时把次要解释移入正文；调整窄屏字号/行高/容器而不使用 `overflow:hidden`；重新检查第 7 页、所有长标题、键盘、打印和投影视口。
- **预期输出：** 手机完整可读、投影层级不回退、内容无丢失的新版本。
- **验收证据：** 390px 页面无裁切或横向滚动；标题全文仍在 DOM；1280px 与打印预览未出现新问题；builder check 与实际浏览器检查均通过。
