/goal 编译并验证一个待人工批准的 AI 网站最小假设页合同。
任务包：网站/落地页改版包；仅使用单页承诺、主 CTA 和本地 HTML 检查，不扩展到完整站点。
领域包：AI 工具站包；把页面中的价值承诺明确标成待验证假设，不写未经支持的市场结论。
工具栈：广域来源优先 Agent Reach，先运行 agent-reach doctor 或确认渠道可用，不可用时回退公开网页阅读器；公开页面结构化抽取可用 Scrapling；动态页验证仅在授权后使用 browser-use；Claude for Chrome 仅作为用户授权的 Chrome 协作选项；CLI 只做确定性门禁与白名单文件写入。
阶段 1 - 广域调研：检索 15-25 个候选来源，覆盖与一个候选用户问题直接相关的公开记录，并记录工具/渠道、检索日期、来源类型与访问限制。
阶段 2 - Deep Research：对需求声明进行至少两个独立来源的交叉核对，显式保留矛盾与低置信度。
阶段 3 - 业务应用：仅把通过来源门禁的假设写入页面草案，等待真人编辑指标并批准。
输出物：语义 JSON、router/gate JSON、待审批 Goal Contract、失败日志和待执行 HTML 模板。
质量门槛：研究声明至少 2 个独立来源；记录来源强弱、工具/渠道和访问限制；过期、营销或不可访问证据降级；保留矛盾；低置信度只能写为假设。
验证方式：先检查来源证据包，再核对人工审批记录与当前 payload 的无密钥 SHA-256 一致性，最后运行 HTML 结构检查并保存日志。
限制：不把 Agent Reach 描述成无限制全网访问；不使用私域、付费、登录资源或未授权外部操作。
工作边界：Agent/Skill 负责语义编译与默认假设；真人编辑指标并批准；CLI 只做确定性验证与白名单执行。
推进规则：先产出语义合同和证据缺口；证据未齐或人工未批准时立即停在门禁。
停止标准：产物通过行为检查并留下可复核报告，或终止阈值被触发。
暂停条件：缺来源、缺人工签署、payload 与保存的审批记录不一致、需要登录/付费/对外变更或任一检查失败时暂停。
